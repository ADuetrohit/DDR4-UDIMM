# Edge-Connector Symbol and Sheet (288-pin DDR4 UDIMM)

Source: JESD21-C 4.20.26 Rev 1.22, **Table 5 — DDR4 288 Pin UDIMM Pin Wiring Assignments** (UDIMM functions only). 286 of the 288 pins also match the Micron CT8G4DFS8 pin table automatically; the other 2 (pins 263/264) were checked by eye because of a text-layout artifact in the Micron PDF.

The files are generated by `tools/gen_edge_connector.py`:

| File | What it is |
|---|---|
| `hardware/libraries/edge_connector/DDR4_UDIMM_288_pinout.csv` | All 288 pins: board side, JEDEC name, net on this design, how to connect it, symbol part |
| `hardware/libraries/edge_connector/symbol_wizard_part_A.tsv` … `_E.tsv` | Paste-ready rows for Altium's Symbol Wizard |

## The five symbol parts

The pins are grouped by function, not by finger position, so the sheet reads cleanly and consecutive labels (DQ0, DQ1, …) run in order.

| Part | Contents | Pins | Left side | Right side |
|---|---|---|---|---|
| **A** | Data bytes 0–3 | 44 | bytes 0, 1 | bytes 2, 3 |
| **B** | Data bytes 4–7 | 44 | bytes 4, 5 | bytes 6, 7 |
| **C** | Address, command, clock, SPD bus | 41 | A0–A13, WE, A15_CAS, A16_RAS, BA, BG, ACT, PAR | CK0, CK1, CKE, CS, ODT, RESET_N, ALERT_n, SA0–2, SCL, SDA, then 4 unused |
| **D** | Ground | 94 | 47 × VSS | 47 × VSS |
| **E** | Power and unused pins | 65 | 26 VDD, 5 VPP, 2 VTT, VREFCA, VDDSPD | 30 unused (NC, RFU, CB0–7, DM8, DQS8) |

Each byte is listed as DQ*n*…DQ*n+7*, DQS_t, DQS_c, DM.

```
      J1A  DATA bytes 0-3                          J1C  ADDRESS / COMMAND / CLOCK / SPD
     ┌──────────────────────────────┐             ┌──────────────────────────────┐
DQ0 ─┤5   DQ0            DQ16   27 ├─ DQ16    A0 ─┤79  A0            CK0_t   74 ├─ CK0_T
DQ1 ─┤150 DQ1            DQ17  172 ├─ DQ17    A1 ─┤72  A1            CK0_c   75 ├─ CK0_C
 …   │ …                  …        │   …       …   │ …               CK1_t  218 ├─ CK1_T
DM0 ─┤7   DM0_n/DBI0_n   …         │         PAR ─┤222 PARITY        …          │  …
 …   └──────────────────────────────┘             └──────────────────────────────┘
```

## Step 1 — make the library

1. **File → New → Library → Schematic Library**.
2. Save it as `D:\Projects\DDR4-UDIMM\hardware\libraries\DDR4_UDIMM.SchLib`.
3. Right-click the project → **Add Existing to Project** → pick that SchLib.

## Step 2 — Part A with the Symbol Wizard

1. With the SchLib open: **Tools → Symbol Wizard**.
2. **Number of Pins** = `44`. **Layout Style** = `Manual` (so the Side column is used).
3. Open `hardware\libraries\edge_connector\symbol_wizard_part_A.tsv` in Notepad → **Ctrl+A**, **Ctrl+C**.
4. In the wizard grid, click the **first cell under "Group"** (row 1) → **Ctrl+V**. The six columns fill in: Group, Display Name, Designator, Electrical Type, Description, Side.
5. Spot-check: row 1 must read `DQ0`, designator `5`, side `Left`.
6. Bottom-right: **Place → Place Symbol**.

If the paste only fills one column, paste the columns one at a time: copy just Display Name into Display Name, and so on.

## Step 3 — Parts B, C, D, E

Same wizard, same steps, but finish with **Place → Place New Part** so each becomes another part of the same component:

| Part | Number of Pins | File |
|---|---|---|
| B | 44 | `symbol_wizard_part_B.tsv` |
| C | 41 | `symbol_wizard_part_C.tsv` |
| D | 94 | `symbol_wizard_part_D.tsv` |
| E | 65 | `symbol_wizard_part_E.tsv` |

## Step 4 — component properties

| Property | Value |
|---|---|
| Designator | `J?` |
| Comment | `DDR4_UDIMM_288` |
| Description | `DDR4 288-pin UDIMM edge fingers, 0.85 mm pitch (JEDEC MO-309)` |
| Footprint | added later, in the footprint step |

Save the library.

Verify it: `py -3.11 tools/check_edge_symbol.py hardware/libraries/DDR4_UDIMM.SchLib` checks every pin's number, name, part, type, side and description against the TSVs. (The first build passed 288/288; Part A's right side reads bottom-to-top, which is cosmetic only.)

## Step 5 — the EDGE sheet

Add a new sheet `EDGE.SchDoc` to the project and place J1A–J1E. Each pin's **Description** says what to attach:

| Description says | Put on the pin | Pins |
|---|---|---|
| `net DQ0`, `net A0`, `net CK0_T`, … | a **net label** with exactly that name | 125 |
| `net GND`, `net VDD`, `net VPP`, `net VTT`, `net VREFCA`, `net VDDSPD` | a **power port** with that name | 129 |
| `not connected` | a **No-ERC** mark | 34 |

Altium auto-increments label numbers while you keep placing (DQ0 → DQ1 → DQ2), which makes Parts A and B fast.

New nets that first appear on this sheet: **VTT**, **VDDSPD**, **CK1_T/CK1_C**, **SA0–SA2**, **SCL**, **SDA**. Those go to the termination and SPD sheets, which come next.
